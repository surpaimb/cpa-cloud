# Contributing

CPA Cloud is in the specification stage. Discuss the functional requirement and acceptance criteria before implementing a feature.

Contributions must be independently authored or accompanied by explicit source and compatible licensing information. Do not submit renamed, translated, or mechanically rewritten code from the reference projects.

Include tests appropriate to behavior changes, public protocol references, dependency provenance, and documentation of limitations. Never submit credentials, user prompts, or production data.

MIT is the proposed license for original code. The actual license and rights-holder attribution must be settled before accepting external code contributions or publishing a release; no contributor license grant is implied by this planning document.
