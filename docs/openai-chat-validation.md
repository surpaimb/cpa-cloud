# Chat Completions 响应校验

本实现来自 CPA Cloud 的独立接口需求，不移植参考项目代码。用于 `openai-compatible` 的 Chat Completions 转发；不据此声称完整 OpenAI 客户端或其他提供商协议兼容。

- JSON 响应上限 16 MiB，必须是有效对象；非空顶层 `error` 不原样返回，只给固定脱敏错误。工具、未知用量和其余正常对象字段保持原样，不新增或估算用量。
- SSE 使用完整事件边界校验后转发。支持 CRLF、多行 data 和分片读取；每行上限 256 KiB、事件 1 MiB、整流 64 MiB。空事件可跳过，半帧不透传。
- 完整 data 为 `[DONE]` 才表示成功结束，生成内容中出现同样字样不算结束。正常工具调用增量保持原样。
- 顶层 `error` 或 `event: error` 被固定错误替代；首事件失败返回 502，已开始输出后追加脱敏错误事件并结束，不伪造 `[DONE]`，不换号或重放。
- 提前 EOF/半帧记录 interrupted，畸形/超限/错误记录 failed，客户端取消记录 cancelled。落盘仍是原有有界请求元数据，不保存正文；完整 token/尝试/成本账本是独立后续交付。

独立测试包括 JSON 错误、第一帧与部分输出后错误、错误正文中的秘密哨兵、工具参数、内容内假结束标记、多行/CRLF、半帧和超限。实际 HTTP 取消及撤销/持久化由现有工作流测试覆盖。
