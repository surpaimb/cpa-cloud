## 部署范围

同一服务支持 Linux/Windows/macOS，运行于云服务器、公司内网主机或个人电脑。
默认 127.0.0.1:8787；回环 HTTP 仅限本机。跨电脑监听要求 HTTPS 或受明确配置的 TLS 入口保护。
员工直接使用 CC Switch/原生工具，无专用客户端依赖，Key 默认永久有效。

## 分工

1. Go 服务端：独立实现持久化、管理员初始化/会话、员工与 Key、上游 API Key、模型路由及 Chat Completions 请求。
2. 网页后台：登录、员工与 Key、上游、模型、状态页面；使用真实 API，不内置假数据。
3. 会员接入调研：ChatGPT/Codex、Claude、Gemini 按官方来源分别核实导入、授权、刷新与调用条件，明确可实现和阻塞部分。
4. 集成与验收：主任务负责契约协调、启动脚本、跨平台构建、模拟上游端到端测试、来源与发布边界。

先实现 API Key 模拟上游闭环，同时完成三家会员接入的可行性报告；会员支持是产品目标，不因预览仅有 API Key 就视为交付完成。

## 预览验收

初始化管理员 → 网页登录 → 添加上游和路由 → 创建员工/永久 Key → 模型请求及 SSE → 撤销拒绝 → 重启恢复。
任何未完成的持久化统计、会员授权、协议兼容和部署安全能力在交付说明中明确标记。
